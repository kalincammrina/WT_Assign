# CampusFlow — Web Technology Assignment II

A three-part Student Management System for U21CS501 Web Technology Assignment II.

## Modules

1. **Student Registration (Q1):** HTML5, CSS3 and JavaScript validation. The form posts to `php/register.php`.
2. **Student Administration (Q2):** PHP + MySQL CRUD, profile/document upload, metadata storage and authenticated file display.
3. **Student Profile Portal (Q3):** Java Servlet + JSP + JDBC login, dynamic student listing and authenticated file streaming.

The PHP and Servlet modules use the same `student_db` database and the same PHP `uploads/` directory. They have separate authenticated sessions.

## Requirements

- XAMPP with Apache, MySQL and PHP 8+ (`pdo_mysql` and `fileinfo` extensions enabled)
- JDK 11 or 17
- Maven 3.8+
- Apache Tomcat 9 (the source uses `javax.servlet`; Tomcat 10+ requires migration to `jakarta.servlet`)

## 1. Database setup

1. Start MySQL in XAMPP.
2. Open `http://localhost/phpmyadmin`.
3. Import `database/student_db.sql`.
4. Confirm the database is named `student_db` and the tables `students`, `student_files`, and `portal_users` exist.
5. Optional: import `database/demo_seed.sql` once to insert the three fictional sample students and six matching sample file records provided for local testing. Do not run it repeatedly because roll numbers and email addresses are unique.

## 2. Run Question 1 — Registration website

1. Copy the complete `StudentManagementAssignment` folder into `C:\xampp\htdocs\`.
2. Start Apache and MySQL in XAMPP.
3. Open `http://localhost/StudentManagementAssignment/frontend/register.html`.
4. Test empty fields, malformed email, invalid roll number, weak password and a valid registration.
5. A valid form submits to `php/register.php`, which repeats the important checks on the server and stores the student in MySQL.

## 3. Run Question 2 — PHP administration website

1. Ensure `php/includes/db.php` matches your local MySQL host, username and password. XAMPP defaults are often `127.0.0.1`, `root`, and an empty password on a local installation.
2. Ensure `php/uploads/profiles/` and `php/uploads/documents/` are writable by Apache.
3. Generate a password hash from a terminal:

   ```bash
   php -r "echo password_hash('ChangeMe123!', PASSWORD_DEFAULT), PHP_EOL;"
   ```

4. Copy the generated hash and run this in phpMyAdmin:

   ```sql
   INSERT INTO portal_users(username, password_hash)
   VALUES ('admin', 'PASTE_HASH_HERE');
   ```

5. Open `http://localhost/StudentManagementAssignment/php/login.php` and sign in as `admin` using the password you hashed.
6. Use **Add student**, **View**, **Edit**, **Delete**, and the student detail page's file upload form to test CRUD and file metadata.

## 4. Run Question 3 — Java Servlet/JSP portal

1. Install JDK 11+ and Maven 3.8+; configure `JAVA_HOME` and ensure `java` and `mvn` are on `PATH`.
2. Use Apache Tomcat 9. Tomcat 10+ is not compatible with the `javax.servlet` imports in this project.
3. Open `servlet/src/main/java/com/student/DBConnection.java` and set the MySQL URL, username and password to match your XAMPP MySQL installation.
4. Open `servlet/src/main/webapp/WEB-INF/web.xml`. Set `uploadRoot` to the **absolute path of the `php` folder** in this project. For the default Windows setup it is:

   ```xml
   <param-value>C:/xampp/htdocs/StudentManagementAssignment/php</param-value>
   ```

   The database stores paths such as `uploads/profiles/example.jpg`, so `uploadRoot` must point to the folder that contains the `uploads` directory. The optional demo seed inserts file metadata for the six sample files included in `php/uploads/`.
5. Create a portal login. The Servlet module uses jBCrypt and can verify a bcrypt hash generated by PHP:

   ```bash
   php -r "echo password_hash('ChangeMe123!', PASSWORD_BCRYPT), PHP_EOL;"
   ```

   ```sql
   INSERT INTO portal_users(username, password_hash)
   VALUES ('portaladmin', 'PASTE_BCRYPT_HASH_HERE');
   ```

6. From the `servlet/` directory, build the WAR:

   ```bash
   mvn clean package
   ```

7. Copy `servlet/target/student-portal.war` to Tomcat's `webapps/` directory and start Tomcat.
8. Open `http://localhost:8080/student-portal/`, sign in as `portaladmin`, and verify student profiles and uploaded file links.

## 5. Security and validation notes

- JavaScript validates required values, email, roll number, password strength and upload type/size before form submission.
- PHP repeats important registration and upload checks server-side, uses PDO prepared statements, stores password hashes, and generates random storage filenames.
- PHP and Servlet file endpoints require an authenticated session and look up file metadata by database ID. The Servlet endpoint normalizes and checks the resolved file path against the configured upload root.
- JSP values sourced from the database are HTML-escaped before rendering.
- This is an academic demonstration, not a production-ready deployment. Production use also needs HTTPS, CSRF protection, login throttling, stronger authorization design and managed secrets.

## 7. Test checklist

- [ ] Valid registration creates a student row.
- [ ] Invalid email, roll number and weak password are rejected.
- [ ] Unsupported or oversized files are rejected.
- [ ] PHP admin login works and unauthenticated users are redirected.
- [ ] PHP Add, View, Edit and Delete work.
- [ ] File metadata appears on the student's detail page.
- [ ] Servlet login works against a bcrypt hash in `portal_users`.
- [ ] Servlet displays all student records from the same database.
- [ ] Servlet streams an uploaded image/document only to a logged-in user.

## 8. Conclusion

The project demonstrates a student registration form using HTML, CSS and JavaScript with client-side validation. PHP and MySQL provide student CRUD operations and file upload metadata management. Java Servlets, JSP and JDBC retrieve student records and securely stream associated files to authenticated users. The three modules demonstrate front-end development, server-side programming and database connectivity.
